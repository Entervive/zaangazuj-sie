# Zaangażuj się!

Strona projektu promującego wolontariat wśród młodzieży we Wrocławiu.

## Uruchomienie lokalne

Wymagany jest Node.js 20 lub nowszy.

```bash
npm install
npm run dev
```

Aplikacja będzie dostępna pod adresem `http://localhost:3000`.

## Build produkcyjny

```bash
npm run lint
npm run build
npm run preview
```
